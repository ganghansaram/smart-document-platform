### 변환기 특징

이 변환기는 기술문서 특화 변환기로, 일반 변환 도구에서 흔히 발생하는 문제들을 해결하고 있습니다.

**1. 장절번호 평문화**
Word 자동번호(1.1, 1.2.3 등)는 일반 변환 시 누락됩니다. 이 변환기는 Word COM을 통해 자동번호를 텍스트로 삽입한 뒤 변환하므로, HTML에서도 장절번호가 그대로 유지됩니다.

**2. 표 병합 셀 정확 변환**
Word 표의 가로/세로 병합 셀(colspan, rowspan)을 정확하게 변환합니다. python-docx 라이브러리의 알려진 병합 셀 버그를 XML 직접 파싱으로 우회 처리했습니다.

**3. 수식 네이티브 변환 (MathML)**
Word 수식(OMML)을 브라우저 표준인 MathML로 직접 변환합니다. MathJax 등 외부 라이브러리 없이 브라우저에서 바로 렌더링됩니다.

**4. 이미지 경로 커스터마이징**
`--image-prefix` 옵션으로 HTML 내 이미지 경로를 서버 구조에 맞게 지정할 수 있어, 변환 후 별도 후처리 없이 웹에 바로 탑재 가능합니다.

### 사용 방법

- **GUI**: `docx2html.exe` 더블클릭 → 파일 선택 → 변환
- **CLI**: `docx2html.exe 입력.docx -o 출력폴더`
- **웹 프로세스 연동**: BAT에서 호출 가능 (종료코드 0=성공, 1=실패, 2=파일오류)

CLI 옵션 상세 및 BAT 연동 예시는 첨부된 README.md를 참고해주세요.

### 참고사항

- Python 설치 불필요 (단일 EXE, ~23MB)
- 장절번호 전처리 기능 사용 시에만 Microsoft Word 설치 필요
- Word 미설치 환경에서는 `--no-preprocess` 옵션으로 장절번호 전처리를 제외하고 변환 가능

사용 중 문의사항이나 추가 요청사항 있으시면 연락주세요.
