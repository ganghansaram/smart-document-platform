### 이번 버전 (v1.4) 주요 개선

**1. 복합 캡션 번호 정확 재현 — "그림 3-1" 이슈 해결**

기존 버전에서 "그림 3-1" 같은 `STYLEREF` + `SEQ` 합성 구조의 캡션 번호가
어긋나던 문제를 해결했습니다. 원문의 heading 번호 + SEQ 순번을 정확히 합성합니다.

**2. 자동번호 자체 생성 (전처리 불필요)**

Word 자동번호(1.1, 1.2.3 등)를 **Word 없이도** 원본 `numbering.xml` 로부터 자체
생성합니다. Word 미설치 환경에서도 heading 번호가 정확히 표시됩니다.

**3. SEQ 스위치 완전 지원**

- `\r N` — 특정 값으로 리셋
- `\s N` — heading N 변경 시 자동 리셋 ("그림 1-1, 1-2 … 2-1" 패턴)
- `\c` — 현재 값 반복 (참조 시 유용)
- `\* ARABIC | ROMAN | alphabetic` — 포맷 지정

**4. DRM 환경 우회 개선**

회사 DRM 적용 환경에서 전처리 결과 파일이 재잠금되는 문제를 `.docx_1` 확장자
우회로 해결. 별도 2단계 워크플로우 없이 단일 실행으로 변환 가능합니다.

**5. Provenance 메타데이터 embed**

변환된 HTML 첫 줄에 변환기 버전·전처리 모드·일시가 자동 기록됩니다.
고객 제보·디버깅 시 이 주석만 봐도 변환 환경을 즉시 식별 가능합니다:

```html
<!-- converter: smart-doc-platform/docx-converter 1.4.0 | adapter: word_com | date: 2026-04-21T14:30:00+00:00 -->
```

### 기존 기능 (변경 없음)

- 표 병합 셀(colspan/rowspan) 정확 변환
- Word 수식(OMML) → MathML 네이티브 변환
- 이미지 추출 + 해시 중복 제거
- 이미지 경로 커스터마이징 (`--image-prefix`)
- h1~h6 전 계층 지원 (이전 h3 까지만 → h6 확대)

### 사용 방법

- **GUI**: `docx2html.exe` 더블클릭 → 파일 선택 → 변환
- **CLI**: `docx2html.exe 입력.docx -o 출력폴더`
- **웹 프로세스 연동**: BAT 에서 호출 가능 (종료코드 0=성공, 1=실패, 2=파일오류)

CLI 옵션 상세 및 BAT 연동 예시는 첨부된 `README.md` 참고.

### 참고사항

- Python 설치 **불필요** (단일 EXE, ~24 MB)
- Microsoft Word 설치는 **선택** — 없어도 대부분의 문서는 정확히 변환됨
- DRM 적용 환경: 업로드 전 **DRM 해제 필수** (EXE 가 DRM 을 풀지 않음)
- **HTML 출력은 h1~h6 태그를 사용**하므로 귀사 웹페이지의 CSS 에 h5/h6 스타일도
  정의되어 있어야 합니다. (없으면 브라우저 기본값으로 렌더링되어 어색할 수 있음)

### 안티바이러스 관련 안내

PyInstaller 로 생성된 EXE 가 일부 Windows Defender / 사내 AV 에서 **false positive
(오탐)** 로 탐지될 수 있습니다. EXE 자체는 안전하며, 공유 의혹 시:
- 사내 AV 관리자에게 화이트리스트 등록 요청
- 필요 시 소스 코드 전달 (오픈소스 Python + python-docx 기반)
