Smart Document Platform

항공우주 기술 문서를 검색하고, 분석하고, 검증하다

KAI 내부망 환경에 최적화된 AI 기반 기술 문서 플랫폼입니다. 외부 클라우드 의존 없이 조직 내 기술 자산을 즉시 검색하고, 해외 논문을 번역·분석하며, 작성 문서의 품질을 자동으로 검증합니다.

폐쇄망 운용 온프레미스 AI RAG 기반 검색 4개 서브시스템

Smart Document Platform은 항공우주 기술 문서 관리의 세 가지 핵심 과제를 해결하기 위해 설계되었습니다. 첫째, 수천 페이지에 달하는 기술 문서에서 원하는 정보를 찾는 데 드는 시간을 최소화합니다. 둘째, 영어로 작성된 해외 논문과 규격을 한국어로 즉시 번역하여 연구 생산성을 높입니다. 셋째, 문서 작성 품질을 AI가 자동으로 점검하여 인적 오류를 줄입니다.

플랫폼은 인터넷 연결 없이 조직 내부망에서 완전히 동작합니다. KAI 내 AI 인프라(DE-Genie/Ollama)를 활용하여 민감한 기술 자산이 외부로 유출되지 않도록 설계되었으며, Explorer · Notebook · Verify 세 개의 운용 서브시스템과 관리자 런처로 구성됩니다.

납품 및 운용 범위: 본 플랫폼은 기체 설계, 항전, 추진, 시험평가 등 KAI 전 사업 분야의 기술 문서를 단일 인터페이스에서 관리할 수 있도록 설계되었습니다. 현재 KF-21 개발백서, 설계 기준, 규격·표준, 시험평가, 품질인증, 운용정비 등 주요 카테고리가 등록되어 있으며, 관리자 권한으로 콘텐츠를 지속 확장할 수 있습니다.

▲ 플랫폼 런처 — 각 서브시스템으로의 진입점. 역할 기반 접근 제어(RBAC)로 권한 관리.

Explorer Knowledge Explorer
운용 중

기술 문서 전체를 대상으로 하이브리드 RAG 검색(키워드 + 벡터)을 제공하는 지식 탐색 시스템입니다. 문서 트리를 통한 직접 탐색과 AI 채팅을 통한 자연어 질의응답을 동시에 지원하며, 검색 결과는 관련 섹션으로 자동 이동합니다.

  • 하이브리드 검색 (FAISS + bge-m3, RRF 병합)
  • AI 채팅 — 문서 기반 Q&A (스트리밍)
  • 계층형 콘텐츠 트리 내비게이션
  • 섹션 네비게이션 (On this page)
  • 북마크 · 전체 텍스트 검색
  • 다크모드 · 반응형 레이아웃
  • 멀티턴 대화 (세션 이력)
  • 쿼리 재작성 (후속 질문 독립화)

운용 중

영문 기술 논문 및 규격 PDF를 업로드하면 페이지별 AI 번역과 함께 요약·Q&A·마인드맵·마킹 등 심층 분석 도구를 제공하는 연구 노트 시스템입니다. 원문 PDF와 번역 결과를 나란히 비교하는 듀얼 패널 뷰어로 번역 품질을 즉시 확인할 수 있습니다.

  • PDF 번역 (pdf2zh, 레이아웃 보존)

  • Q&A 챗봇 — 문서 기반 질의응답

  • 폴더 관리 · 드래그앤드롭 정리
  • ZIP 다운로드 · 마크다운 편집기

운용 중

원본 문서와 수정본을 비교하고, 작성 규칙을 자동 점검하며, 표절·유사도를 검사하는 통합 문서 검증 시스템입니다. 21종 규칙 엔진이 번호 연속성, 용어 통일, 문장 길이 등을 자동으로 검사하고, Acrolinx 방식의 품질 스코어로 문서 완성도를 수치화합니다.

  • 문서 비교 — 단어 수준 Diff + AI 의미 분류
  • 유사도 검사 (Winnowing + bge-m3 임베딩)
  • 규칙 검증 — 21종 자동 점검
  • 품질 스코어링 (Acrolinx 밀도 방식)
  • 수락/거절 판정 워크플로
  • 검토 리포트 내보내기 (XLSX · HTML · TXT)
  • 스크롤바 미니맵 (변경점 위치 시각화)
  • 세션 이력 관리

즉각적인 정보 접근

🛡️

보안 완전 내재화

폐쇄망 온프레미스 운용. 기술 자산이 외부 클라우드에 전송되지 않아 보안 규정 완전 준수.

📋

문서 품질 자동 검증

21종 규칙 엔진으로 작성 기준 자동 점검. 리뷰 시간 단축, 문서 완성도 수치화.

🔗

통합 지식 관리

설계·시험·규격·운용 문서를 단일 인터페이스에서 탐색. 팀 간 지식 공유 촉진.

🔄

지속 확장 가능 구조

관리자 콘솔에서 콘텐츠·메뉴·설정을 실시간 관리. 코드 수정 없이 플랫폼 확장 가능.

도입 및 관리

빠른 시작

플랫폼은 두 개의 프로세스(백엔드 + 정적 파일 서버)만으로 즉시 구동됩니다. 별도의 빌드 과정이나 외부 서비스 연동이 불필요합니다.

역할명령접속 주소
백엔드 API cd backend && python main.py http://localhost:8000
프론트엔드 python -m http.server 8080 http://localhost:8080

콘텐츠 관리 (관리자)

관리자 권한으로 로그인하면 Explorer 상단에 Edit 메뉴가 활성화됩니다. 콘텐츠 파일(HTML 웹북)을 업로드하고, 메뉴 트리를 드래그&드롭으로 재구성하며, AI·검색·보안 설정을 GUI에서 조정할 수 있습니다. 메뉴 구조 변경은 즉시 전체 사용자에게 반영됩니다.

  • 콘텐츠 등록: Edit → 파일 업로드 → 메뉴 트리에서 위치 지정
  • 메뉴 관리: Edit → 메뉴 편집 → 드래그앤드롭으로 순서 조정
  • 설정 관리: Edit → 관리자 설정 → AI 모델·검색·보안·화면 탭별 조정
  • 검색 인덱스 재생성: 콘텐츠 업로드 시 자동 재생성 (수동 트리거도 가능)

사용자 계정 및 권한

계정은 data/users.json에서 관리하며, 역할(viewer · editor · admin)에 따라 콘텐츠 조회, 편집, 관리자 기능 접근이 구분됩니다. 초기 관리자 계정 설정 후 팀별로 viewer 계정을 배포하여 운용합니다.

지원 및 문의: 플랫폼 운용 중 발생하는 기술적 문의사항은 시스템 관리자에게 문의하세요. 각 서브시스템의 상세 사용 방법은 좌측 메뉴 플랫폼 가이드 하위 항목을 참조하십시오.
