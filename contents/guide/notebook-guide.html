Research Notebook

논문 번역 및 문서 분석 시스템

Notebook은 영문 기술 논문 및 규격 PDF를 업로드하여 페이지별 AI 번역, 요약, Q&A, 마인드맵, 마킹 등 문서 분석 도구를 제공하는 연구 노트 시스템입니다.

PDF 번역 AI 요약 Q&A 챗봇 마킹·메모 폴더 관리

사용 흐름은 PDF 업로드 → 문서 열기 → 번역 → AI 분석 → 내보내기 순서입니다. 원문 PDF와 번역 결과를 나란히 비교하는 듀얼 패널 뷰어를 지원하며, 우측 도구 패널에서 요약, Q&A, 마인드맵, 마킹 등을 수행합니다.

Notebook 문서 목록 — 업로드, 폴더 관리, 문서 카드

문서 관리

PDF 파일을 업로드하면 문서 카드가 생성됩니다. 폴더를 만들어 문서를 분류하고, 트리 패널에서 계층 구조로 탐색할 수 있습니다.

기능 설명
업로드 PDF 파일을 드래그앤드롭하거나 업로드 버튼으로 등록합니다. 최대 100MB.
문서 카드 타일/리스트 뷰 전환 가능. 제목 편집, 삭제를 지원합니다.
폴더 관리 폴더 생성, 이름 변경, 삭제. 문서를 드래그앤드롭으로 폴더 간 이동할 수 있습니다.
트리 패널 좌측 오버레이로 폴더 구조를 표시합니다. 핀 고정하면 상시 표시됩니다.
문서 검색 본문 텍스트와 메모를 대상으로 검색합니다.

PDF 뷰어

문서 카드를 클릭하면 듀얼 패널 뷰어가 열립니다. 좌측에 원문 PDF, 우측에 번역 결과 또는 AI 도구가 표시됩니다.

듀얼 패널 뷰어 — 좌측 원문 PDF, 우측 AI 도구 패널

기능 설명
페이지 이동 이전/다음 버튼 또는 페이지 번호 표시로 이동합니다.
확대/축소 +/- 버튼으로 조절합니다. 클릭 시 기본 크기로 복원됩니다.
패널 크기 조절 좌우 패널 사이의 구분선을 드래그하여 비율을 조정합니다.
우측 도구 패널 우측 아이콘 레일에서 번역, 메모, 용어집, AI 분석 탭을 전환합니다.

번역

두 가지 번역 모드를 제공합니다. 우측 아이콘 레일에서 모드를 전환하며, 모델 선택 후 번역을 실행합니다.

모드 엔진 특징
PDF 번역 pdf2zh 원문 레이아웃을 보존한 번역 PDF를 생성합니다. 페이지별 또는 범위 지정(최대 5페이지) 번역을 지원합니다.
웹뷰 번역 PyMuPDF4LLM + Ollama PDF에서 텍스트를 추출하여 마크다운으로 번역합니다. 폰트 크기 조절(12~22px), 전체 문서 연속 스크롤, 마크다운 편집을 지원합니다.

번역 실행 후 상태가 3초 간격으로 갱신되며, 완료 시 우측 패널에 결과가 표시됩니다. PDF 모드에서는 스크롤 동기화를 켜면 원문과 번역본이 함께 스크롤됩니다.

AI 분석

우측 아이콘 레일에서 AI 분석 탭을 선택하면 요약, Q&A, 마인드맵 세 가지 도구를 사용할 수 있습니다. 최초 사용 시 "문서 분석" 버튼을 클릭하여 문서 전체를 분석합니다. 분석은 문서당 1회 수행됩니다.

AI 요약

문서 전체를 분석하여 요약문, 키워드, 섹션별 요약을 생성합니다. 문서 크기에 따라 단일 패스 또는 계층적 요약 방식이 자동 선택됩니다.

  • 전체 요약문 — 문서 핵심 내용 요약
  • 키워드 추출 — 태그 형태로 표시
  • 섹션별 요약 — 접기/펼치기 가능
  • 재생성 버튼으로 다시 분석 가능

Q&A 챗봇

해당 문서를 기반으로 질문에 답변하는 채팅 인터페이스입니다. 답변은 실시간 스트리밍으로 표시되며, 출처 페이지 번호가 함께 제공됩니다.

  • 문서 기반 질의응답 — 해당 문서 내용에서 답변 생성
  • 멀티턴 대화 — 이전 질문 맥락 유지
  • 출처 페이지 표시 — 클릭 시 해당 페이지로 이동
  • 빠른 질문 버튼 — 요약, 핵심 내용, 방법론

마인드맵

문서 구조를 트리 형태로 시각화합니다. 노드를 클릭하면 AI가 해당 섹션에 대한 설명을 생성합니다. 확대/축소, 전체 펼치기/접기 컨트롤을 제공합니다.

마킹·메모

좌측 원문 PDF에서 텍스트를 선택하면 마킹 도구가 표시됩니다. 형광펜 색상을 선택하고 메모를 입력하면 해당 위치에 표시가 남습니다.

기능 설명
형광펜 노랑, 초록, 빨강, 파랑 4색 중 선택하여 텍스트를 마킹합니다.
메모 마킹에 메모를 추가할 수 있습니다. 마킹 위에 마우스를 올리면 메모가 표시됩니다.
선택 번역 선택한 텍스트를 즉시 번역하는 팝업을 제공합니다.
선택 요약 선택한 텍스트의 요약을 생성합니다.
메모 패널 우측 메모 탭에서 전체 마킹 목록을 확인합니다. 클릭 시 해당 페이지로 이동합니다.

내보내기

상단 도구 모음의 다운로드 메뉴에서 다양한 형식으로 내보낼 수 있습니다. 번역 상태에 따라 사용 가능한 옵션이 달라집니다.

형식 조건 설명
원본 PDF 항상 가능 업로드한 원본 파일 다운로드
번역 PDF (페이지) PDF 번역 완료 시 현재 페이지의 번역 PDF 다운로드
마크다운 (페이지) 웹뷰 번역 완료 시 현재 페이지의 번역 마크다운 다운로드
마크다운 (전체) 웹뷰 번역 1건 이상 전체 문서 번역 마크다운 다운로드
ZIP 웹뷰 번역 1건 이상 마크다운 + 이미지 에셋 압축 파일
마크다운 편집: 웹뷰 번역이 완료된 페이지에서 편집 버튼을 클릭하면 마크다운 편집기가 열립니다. 편집 내용은 저장 시 전체 문서에 자동 반영됩니다.
참고: 번역 및 AI 분석에는 Ollama 모델이 사용됩니다. 사용 가능한 모델 목록은 시스템 환경에 따라 다르며, 관리자 설정에서 확인할 수 있습니다.
