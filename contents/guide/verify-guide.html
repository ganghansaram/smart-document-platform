문서 검증 시스템 소개

Verify는 기술 문서의 유사도 검사, 문서 비교, 규칙 검증을 수행하는 통합 검증 도구입니다. 3대 국제 규격 기반 21종 규칙 엔진과 품질 스코어링을 제공합니다.

유사도 검사 문서 비교 규칙 검증 21종 규칙 엔진 품질 스코어링

Verify는 세 가지 독립된 검증 모드를 제공합니다. 모드별로 문서를 업로드하거나 텍스트를 붙여넣어 검증을 실행하며, 결과는 PDF·HTML 보고서로 내보낼 수 있습니다.

Verify 메인 화면 — 세 가지 검증 모드 선택

유사도 검사

유사도 검사는 지금 작성 중인 문서가 사내 기존 문서나 외부 공개된 타 기관·타사 문서와 얼마나 겹치는지 문장 단위로 비교하는 도구입니다. 작성 단계에서 의도치 않은 중복 구간을 미리 발견하고, 외부에 공개·배포하기 전에는 우연 일치로 인한 저작권·인용 출처 누락 리스크를 차단하기 위해 사용합니다.

주의 유사도 ≠ 표절. 이 점수는 텍스트가 얼마나 겹치는지를 수치로 보여줄 뿐, 표절 여부를 자동 판정하지 않습니다. 합법적 인용·정형구문·약어·규격 번호도 매칭으로 잡힙니다. 최종 판단은 검토자가 매칭 카드를 하나씩 확인한 뒤 내립니다. (출처: Crossref Similarity Check 가이드라인)
5분 안에 첫 검사 돌리기

검사 대상 1건 + 비교 원본 1건만 있으면 검사·결과 해석·보고서 산출까지 5분이면 됩니다. 세부 옵션은 결과를 본 다음에 조정해도 점수가 즉시 재계산되므로 처음에는 기본값으로 시작합니다.

시나리오별 사용법

실제 문서 작성 흐름에서 유사도 검사를 어떻게 쓰는지 세 가지 대표 시나리오로 정리했습니다. 아래 시나리오는 사내 문서 작성·검토·외부 공개 단계를 그대로 따라갑니다.

시나리오 1

신규 문서 작성 중 — 사내 기존 문서와의 중복 회피

과거 문서를 일부 차용·재활용하는 경우가 많은 만큼, 초안 작성 단계에서 사내 기존 문서와 의도치 않게 중복된 구간을 조기에 발견합니다.

  1. 허브에서 유사도 검사 카드 진입 후, 좌측 검사문서에 작성 중인 초안을 업로드합니다. (`.docx` / `.pdf` / `.doc` 또는 텍스트 붙여넣기)
  2. 우측 비교문서에 비교할 사내 기존 문서 1건을 업로드합니다. (여러 건과 비교하려면 한 건씩 반복 — 검사 결과는 사이드바 하단 최근 작업에 자동 누적)
  3. 유사도 검사 실행 후 점수와 5단계 신호등을 먼저 확인합니다. Yellow(25~49%) 이상이면 사이드바 동일 · 거의 동일 카테고리 카드부터 우선 검토합니다.
  4. 매칭 카드를 클릭하면 본문 좌·우 패널이 해당 문장으로 동시 스크롤합니다. 의도된 재활용이면 그대로 두고, 의도치 않은 중복이면 초안을 즉시 수정합니다.
  5. 수정 후 유사도 검사를 다시 실행하여 점수가 충분히 떨어졌는지 확인합니다. (보통 Yellow → Green 진입을 1차 목표로 둡니다.)
💡 팁. 정형구문·목차·캡션은 기본으로 자동 제외되므로, 점수가 Green 이어도 "양호"가 보장되지는 않습니다. 동일 카테고리가 1건이라도 잡히면 그 구간은 반드시 직접 봅니다.
시나리오 2

공개·배포 전 최종 점검 — 외부 문서와의 우연 일치 차단

외부에 공개된 타 기관·타사 문서와 우연히 유사해진 구간이 있는지 공개·배포 전 마지막으로 확인합니다. 저작권 이슈와 출처 누락을 사전에 차단하기 위한 점검입니다.

  1. 검사문서에 공개 전 최종본을, 비교문서에 외부 공개 타 기관·타사 문서를 업로드합니다. (PDF 형식이 흔하므로 그대로 업로드 가능 — 텍스트 추출은 자동)
  2. 인용·출처 표시 제외 옵션은 OFF로 두고 검사합니다. (인용 표기를 했더라도 우연 일치는 검출 대상)
  3. 결과에서 거의 동일·의역 카테고리를 우선 봅니다. 동일 매칭은 자사 표준·정형구문일 가능성이 크지만, 의역은 우연 일치로 보기 어려운 신호입니다.
  4. 의역 매칭 카드를 모두 검토 후, 우연 일치로 판단되는 구간만 ⓧ → 수동 제외 (사유: "우연 일치 — 검토 완료") 처리합니다. 점수는 즉시 재계산되며, 직후 5초간 [↺ 복원] 토스트가 노출됩니다.
  5. 모든 검토 완료 후 시나리오 ③ 으로 이동하여 회람용 PDF 보고서를 산출합니다.
💡 팁. 한국어로 작성된 자사 문서와 영문 외부 문서를 비교할 때는 의역 카테고리에 한↔영 번역 매칭이 통합되어 표시됩니다. 다국어 매칭이 약한 유사로 떨어지는 경우는 진단 트리 §3 을 참고합니다.
시나리오 3

회람·승인용 PDF 보고서 만들기

검사 결과를 검토 회람·승인 라인이 한 페이지로 즉시 이해하도록 PDF로 산출합니다. 결과지 + 매칭 상세 + 검사 기준이 자동 분리됩니다.

  1. 검사 결과 화면에서 수동 제외·검사 설정이 최종 의도대로 맞춰져 있는지 확인합니다. (보고서는 현재 점수를 그대로 캡처합니다.)
  2. 우측 사이드바 헤더의 내보내기 버튼 클릭 → PDF (권장) 선택. HTML 은 인쇄가 필요 없는 웹 회람 용도에만 사용합니다.
  3. 보고서는 자동으로 3 페이지로 구성됩니다 — ① 결과지 (A4 1장, 점수·누적바·메타·검사 기준 요약) + ② 별첨 A 매칭 상세 (카테고리별 그룹 + 자동/수동 제외 영역) + ③ 별첨 B 검사 기준 (산식·임계값·SSOT)
  4. 검토 회람 시에는 결과지(1p)만 첨부하고, 검토 부서·기록 보관용에는 전체 3페이지를 보관합니다.
  5. 보고서를 흑백 프린터로 인쇄할 때는 브라우저 인쇄 대화상자에서 "배경 그래픽" 옵션을 반드시 켭니다. (카테고리 색상이 보존되어 흑백 인쇄에서도 매칭 강도 식별 가능)

카테고리 — 매칭 강도 4단계

유사도 검사는 매칭을 강도에 따라 4 카테고리로 자동 분류합니다. 동일 베이스 문장이 4단계로 어떻게 변형되는지 실제 기술 문서 예시로 비교합니다. (분류 체계는 Copyleaks Identical / Minor Changes / Paraphrased 를 모방하고, 사내 검토용 1 카테고리 "약한 유사" 를 추가한 4 카테고리입니다.)

마킹 읽는 법: 전체 매칭 동일 구간 공통 단어 그대로 일치 바뀐 단어 동의어 치환 의미 키워드 의역 대응 쌍 약한 매칭 부분 겹침

점수 산식과 5단계 신호등

유사율은 다음 산식으로 계산됩니다 — Copyleaks aggregatedScore 모방, 가중치 없음.

유사율 = (동일 + 거의 동일 + 의역) / (전체 문장 - 제외 문장) × 100
  • 동일 / 거의 동일 / 의역 — 동등 가중치(1)로 합산. 약한 유사는 점수에서 제외 (참고용).
  • 제외 문장 — 자동 제외(정형구문·목차·캡션·참고문헌·규격번호) + 수동 제외(검토자 ⓧ 판정).
  • 검증 사례 — Copyleaks 샘플 리포트와 동일 결과: (76 + 50 + 89) / (597 - 105) = 43.7%.

산출된 점수는 Turnitin 산업 표준 5단계 신호등으로 표시됩니다.

상황별 진단 — 결과가 예상과 다를 때

실제 사용 중 자주 마주치는 4 가지 상황을 진단 트리 형태로 정리했습니다. 항목을 펼쳐 단계별로 따라가면 원인과 대응을 확인할 수 있습니다.

점수가 예상보다 낮게 나옵니다

검사 설정에서 자동 제외 옵션이 모두 ON 인지 확인하셨나요?

예
정형구문·목차·캡션이 자동 제외되면 점수가 의도보다 낮아 보일 수 있습니다. 사이드바 하단 제외된 N건 보기 패널을 펼쳐 어떤 매칭이 제외됐는지 직접 확인합니다. 일부 옵션을 OFF 로 두면 해당 매칭이 점수에 다시 포함됩니다 (재계산은 즉시).
아니오
설정 패널을 펼쳐 5 옵션 상태를 먼저 점검합니다. 인용·출처 표시 제외(기본 OFF) 가 ON 으로 변경됐다면 인용 구간 전체가 점수에서 빠집니다.

매칭이 정말 적은 것인지 시각 확인했나요?

본문 패널 우측 미니맵에 색상 마커가 거의 없다면, 검사 대상 자체가 비교 원본과 충분히 독창적입니다. 추가 비교 원본을 시도하거나, 약한 유사 카테고리를 켜서 회색 매칭까지 확인합니다.

점수가 노랑·주황 구간입니다 — 어떻게 대응할까

5 단계 신호등의 Yellow(25~49%) 또는 Orange(50~74%) 구간입니다. 점수보다 어느 카테고리가 점수를 끌어올렸는지가 중요합니다.

사이드바에서 동일 카테고리 카운트가 0 이 아닌가요?

예
동일 매칭은 단어까지 같은 직접 차용입니다. 카드를 모두 클릭하여 본문 위치를 확인하고, 의도된 인용/표준 문구가 아니면 즉시 재서술합니다.
아니오
거의 동일·의역 위주라면 표현은 다르나 의미가 같은 구간이 누적되어 점수가 올라간 상태입니다. 의역 매칭부터 검토하여 우연 일치/표준 표현이 아닌 구간만 재작성합니다.

검토 후에도 점수가 떨어지지 않으면?

의도된 재활용·표준 문구라면 ⓧ 수동 제외로 점수에서 제거합니다 (사유: "표준 문구 — 재활용 의도", "정상 인용 — 출처 표기 완료" 등). 보고서에 사유가 기록되어 검토자가 판단 근거를 즉시 확인할 수 있습니다.

다른 언어 매칭이 잘 안 잡힙니다 (한↔영)

bge-m3 다국어 임베딩은 monolingual(같은 언어) 비교 대비 cross-lingual(다른 언어) 점수 분포가 전반적으로 낮습니다. 의역 카테고리에 한↔영 번역이 통합되도록 설계되어 있으나, 임계값(sem ≥ 0.75)을 넘지 못한 매칭은 약한 유사로 떨어집니다.

약한 유사 카테고리 필터가 켜져 있나요?

아니오 (기본값)
사이드바 결과 필터에서 약한 유사 칩을 켭니다. 회색 매칭 카드가 추가로 노출됩니다 (점수에는 영향 없음 — 표시만).

그래도 의심 구간이 안 보이면?

사람이 직접 짧은 영문 인용/번역 의심 구간을 발췌하여 비교 원본의 해당 영문 단락만 잘라 텍스트 붙여넣기로 재검사합니다. 짧은 구간만 비교하면 cross-lingual 임계값을 넘기 쉽습니다.

일부 매칭만 제외하고 다시 점수 계산하기

검토 결과 "이 매칭은 표절이 아니라 의도된 재활용/정상 인용/표준 문구" 라고 판정한 카드는 수동 제외합니다.

매칭 카드 우측 ⓧ 버튼이 보이나요?

예
ⓧ 클릭 → 사유 선택 모달에서 사유를 고르거나 "기타" 입력 → 제외. 점수가 즉시 차감되며, 직후 5초간 토스트 [↺ 복원]이 노출됩니다.
아니오
자동 제외된 매칭(예: 정형구문·캡션) 카드는 사이드바 메인 리스트에 노출되지 않습니다. 사이드바 하단 제외된 N건 보기 패널을 펼쳐서 확인할 수 있습니다.

잘못 제외해서 되돌리고 싶다면?

5초 안이라면 토스트 [↺ 복원]을 클릭합니다. 그 후에는 제외된 N건 보기 패널을 펼쳐 해당 카드의 [↺ 복원] 버튼으로 점수에 다시 포함시킵니다. (수동 제외는 세션 동안만 유지되며, 보고서 산출 시점의 상태가 보존됩니다.)

보고서 양식

사이드바 상단 내보내기 버튼으로 PDF·HTML 두 형식의 보고서를 산출합니다. 회람·승인용은 PDF, 웹 회람용은 HTML 을 사용합니다.

형식용도특징
PDF (권장)인쇄·배포·회람용A4 자동 분할, 색상 보존, 백엔드 정밀 변환 (WeasyPrint)
HTML웹뷰 — 인쇄 외 용도브라우저로 열어 검토, 동일 양식

보고서 양식은 결과지(A4 1장) + 별첨 A 매칭 상세 + 별첨 B 검사 기준 3 페이지 구조입니다. 결과지는 메타데이터·점수 카드·매칭 카테고리 분포·출처·검사 기준 요약을 한 페이지에 담고, 별첨 A 는 카테고리별 매칭 카드(동일/거의 동일/의역/약한 유사 + 자동/수동 제외)를 그룹핑하여 표시합니다.

대표 규칙 예시

자주 검출되는 규칙 세 가지를 소개합니다.

STE-3.1 절차문 길이 제한 (20단어)

ASD-STE100은 절차문을 20단어 이하로 작성하도록 규정합니다. 긴 문장은 번역 오류를 유발하고 현장 작업자의 이해도를 떨어뜨립니다.

원문: "Before you start the installation procedure, make sure that all the safety pins are removed and the access panels are open and secured in the up position." — 29단어, 초과
개선: "Remove all safety pins. Open the access panels and secure them in the up position. Start the installation procedure." — 각 10단어 이하

Custom 번호 연속성 검사

섹션 번호가 건너뛰거나(1.1 → 1.2 → 1.4) 계층이 갑자기 변경되는(3.2.1 → 3.3) 오류를 감지합니다. 기술 문서에서 번호 누락은 교차참조 오류로 이어집니다.

검출: "3.1 → 3.2 → 3.4" — 오류: 번호 3.3 누락

38-A1 약어 첫 사용 시 풀네임 정의

MIL-STD-961E(4.6.3)와 MIL-STD-38784B(4.8)의 공통 요구사항입니다. 약어를 처음 사용할 때 풀네임을 함께 표기해야 하며, 미정의 약어는 경고로 분류됩니다.

검출: "The FCS shall comply with..." — 경고: FCS 풀네임 미정의

자동화 등급과 제외 기준

총 78개 규칙(규격 72개 + 사내 6개)을 자동화 가능성에 따라 세 등급으로 분류하였습니다.

등급 정밀도 구현 설명
A등급 90% 이상 우선 구현 정규식, 사전 기반. 오탐 거의 없음. 예: 문장 길이, 필수 섹션 존재, 약어 정의
B등급 60~90% 일부 비활성 휴리스틱 기반. 오탐 가능성 있어 기본 OFF인 규칙 포함. 예: 수동태, 명사 클러스터
C등급 — 제외 인간 판단 또는 고급 NLP 필요. 폐쇄망 환경에서 자동화 불가. 57개 해당
폐쇄망 환경 제약: 형태소 분석, 품사 태깅 등 대규모 NLP 모델을 상시 운용하기 어려운 환경 특성상, NLP 의존 규칙 18개(문맥 기반 용어 선택, 동사 형태 판별 등)와 주관적 판단 규칙 10개는 현 단계에서 제외하였습니다. 향후 NLP 인프라 확충 시 단계적으로 추가할 수 있습니다.

품질 스코어링

검출된 이슈의 밀도(100단어당 가중 이슈 수)를 기반으로 문서 품질을 수치화합니다. Acrolinx의 밀도 기반 스코어링 방식을 채택하였습니다.

등급 점수 판정
A 90 – 100 우수 — 출판 가능 수준
B 70 – 89 양호 — 경미한 수정 후 승인 가능
C 50 – 69 보통 — 상당한 수정 필요
D 0 – 49 미흡 — 전면 재검토 권장

이슈 심각도에 따라 가중치가 다릅니다. 오류(error)는 5, 경고(warning)는 2, 제안(suggestion)은 1이며, 규칙 신뢰도(confidence)를 곱하여 최종 밀도를 산출합니다. 오류 항목을 우선 해결하는 것이 점수 개선에 가장 효과적입니다.
