Document Verify System

문서 검증 시스템 소개

Verify는 기술 문서의 유사도 검사, 문서 비교, 규칙 검증을 수행하는 통합 검증 도구입니다. 3대 국제 규격 기반 21종 규칙 엔진과 품질 스코어링을 제공합니다.

유사도 검사 문서 비교 규칙 검증 21종 규칙 엔진 품질 스코어링

Verify는 세 가지 독립된 검증 모드를 제공합니다. 모드별로 문서를 업로드하거나 텍스트를 붙여넣어 검증을 실행하며, 결과는 XLSX, HTML, TXT 형식으로 내보낼 수 있습니다.

Verify 메인 화면 — 세 가지 검증 모드 선택

유사도 검사

Similarity Check

두 문서 간 텍스트 유사도를 측정합니다. Winnowing 핑거프린트로 표면적 복사를 감지하고, bge-m3 벡터 임베딩으로 의미적 유사성까지 포착합니다.

  • 하이브리드 유사도 분석 (Winnowing + bge-m3 임베딩)
  • 유사 구간 하이라이트 표시
  • 유사도 수치 제공 — 텍스트, 의미, 종합 백분율
  • 세션별 비교 이력 관리

유사도 검사 결과 — 유사 구간 하이라이트 및 수치 표시

유사도 ≠ 표절

본 시스템이 산출한 유사도 점수는 텍스트 유사도를 측정한 것일 뿐, 표절 여부를 자동 판정하지 않습니다.

합법적 인용, 정형구문, 약어, 규격 번호 등도 매칭될 수 있으므로 반드시 검토자가 매칭 항목을 직접 검토해야 합니다. (Crossref Similarity Check 공식 가이드라인)

분류 체계 — 4 카테고리 (Copyleaks 모방)

결과는 매칭 강도에 따라 4 카테고리로 분류되어 사이드바와 보고서에 일관 표시됩니다. 추가로 자동/수동 제외된 매칭은 제외 패널에서 별도 확인할 수 있습니다.

카테고리색상설명점수 영향
동일🔴 빨강단어까지 거의 그대로 일치점수에 포함
거의 동일🟧 연빨강단어 일부만 바꾼 구간점수에 포함
의역🟪 보라표현은 다르나 같은 의미 (다른 언어 번역 포함)점수에 포함
약한 유사⚪ 회색부분 의미 겹침, 차용 단정 어려움 — 검토자 판단 영역점수 제외 (참고용)

각 카테고리는 어휘 일치도(Winnowing fingerprint)와 의미 유사도 (bge-m3 embedding) 두 축의 조합으로 자동 결정됩니다. 단순 % 임계값 한 가지로 분류되지 않습니다.

카테고리어휘 유사의미 유사기술 임계값
동일매우 높음—fp ≥ 85%
거의 동일높음높음fp 40~85% + sem ≥ 0.85
의역낮음높음fp < 40% + sem ≥ 0.75 (다른 언어 번역 포함)
약한 유사낮음중간sem 0.65~0.75

점수 카드 옆 ⓘ 클릭 시 산식·5단계 신호등을, 누적바 우측 ⓘ 클릭 시 2축 다이어그램과 카테고리 정의를 볼 수 있습니다.

점수 산출법 (Copyleaks 공식)

유사율은 다음 산식으로 계산됩니다 (가중치 없음 — Copyleaks aggregatedScore 모방).

유사율 = (동일 + 거의 동일 + 의역) / (전체 문장 - 제외 문장) × 100
  • 동일 / 거의 동일 / 의역 — 점수에 동등 가중치(1)로 합산. 약한 유사는 참고용으로 점수에서 제외
  • 제외 문장 — 자동 제외 (정형구문·목차·캡션·참고문헌·규격번호) + 수동 제외 (사용자 ⓧ 판정)
  • 검증 — Copyleaks 샘플 리포트와 동일 결과: (76+50+89)/(597-105) = 43.7%

결과 점수는 Turnitin 산업 표준 5단계 신호등으로 표시됩니다.

색상구간의미
Blue0%매칭 없음 — 완전 독창
Green1~24%양호 — 정상 인용·정형구문 수준
Yellow25~49%검토 필요 — 출처 표기·재서술 점검
Orange50~74%상당량 매칭 — 광범위한 재작성 권고
Red75~100%위험 — 대부분이 타 출처와 동일

도구·알고리즘 근거

본 시스템의 분류 로직은 두 계층으로 구성됩니다.

  • L1: Winnowing fingerprint — character k-gram (k=25) + sliding window (w=4) Rabin-Karp 해시. Schleimer, Wilkerson, Aiken (SIGMOD 2003)
  • L3: bge-m3 multilingual embedding — 1024차원 cosine similarity. BAAI (2024) — 다국어 의미 유사도

분류 체계는 Copyleaks의 detection levels (Identical / Minor Changes / Paraphrased)를 기반으로 우리 도메인 특화 1 카테고리(약한 유사)를 추가한 4 카테고리입니다. 분류 임계값과 보고서 양식은 Turnitin Similarity, iThenticate v2, Crossref Similarity Check의 공식 가이드라인을 참고하여 설정되었습니다.

보고서 출력 활용법

사이드바 상단 내보내기 버튼으로 PDF·HTML 두 형식의 보고서를 생성할 수 있습니다.

형식용도특징
PDF (권장)인쇄·배포·회람용A4 자동 분할, 색상 보존, 백엔드 정밀 변환 (WeasyPrint)
HTML웹뷰 — 인쇄 외 용도브라우저로 열어 검토, 동일 양식

보고서 양식은 결과지(A4 1장) + 별첨 A 매칭 상세 + 별첨 B 검사 기준 3 페이지 구조입니다. 결과지는 메타데이터·점수 카드·매칭 카테고리 분포· 출처·검사 기준 요약을 한 페이지에 담고, 별첨 A는 카테고리별 매칭 카드(동일/거의 동일/의역/약한 유사 + 자동/수동 제외)를 그룹핑하여 표시합니다.

자주 묻는 질문

Q. 점수가 의외로 낮게 나왔습니다. 시스템이 잘못된 것 아닌가요?

A. 정형구문·목차·캡션 등이 자동 제외된 결과일 수 있습니다. 검사 설정 패널에서 옵션을 끄거나, 하이라이트된 매칭 카드를 직접 확인해 주세요.

Q. 한국어 문서와 영문 표준서를 비교했는데 다른 언어 매칭이 잘 안 나옵니다.

A. bge-m3 cross-lingual 점수 분포가 monolingual 대비 낮으므로, 일부 다른 언어 매칭은 "약한 유사"로 분류될 수 있습니다. 의역 카테고리에 다른 언어 번역도 통합되어 있으나 점수 임계값을 넘지 못한 매칭은 약한 유사로 떨어집니다. 매칭 카드를 직접 확인하여 차용 가능성을 검토해 주세요.

Q. 같은 문서를 다시 검사했는데 점수가 약간 다릅니다.

A. 검사 설정의 사용자 토글이 변경되었거나 임계값이 조정된 경우 점수가 재계산됩니다. 동일 조건이라면 동일 결과가 나옵니다.

Q. "거의 동일"과 "의역"의 차이가 모호합니다.

A. 어휘 일치도 차이입니다. 단어 일부만 바꾼 경우는 "거의 동일", 문장을 재구성하여 표현이 달라진 경우는 "의역"입니다. 누적바 우측 ⓘ의 2축 다이어그램에서 시각적으로 확인할 수 있습니다.

Q. 자동 제외 카드는 무엇인가요?

A. 정형구문(예: "the contractor shall"), 목차 헤딩, 표/그림 캡션, 참고문헌 섹션, 규격 번호 단독 매칭 등이 자동으로 제외됩니다. 검사 설정 패널에서 옵션을 토글하면 일부 자동 제외 항목을 점수에 다시 포함할 수 있습니다. 자동 제외된 매칭은 메인 리스트가 아닌 사이드바 하단 "제외된 N건 보기" 패널에서 확인합니다.

Q. 수동 제외와 복원은 어떻게 하나요?

A. 매칭 카드 우측 ⓧ 클릭 → 사유 선택 → 점수에서 즉시 차감됩니다. 직후 5초간 토스트 [↺ 복원]이 노출되어 즉시 되돌릴 수 있고, 그 후에도 제외 패널에서 [↺ 복원] 버튼으로 복귀 가능합니다.

Q. 보고서를 인쇄했는데 색상이 없어요.

A. 브라우저 인쇄 대화상자에서 "배경 그래픽" 옵션을 켜주세요. 카테고리 색상이 보존되어 흑백 인쇄 시에도 매칭 강도를 식별할 수 있습니다.

규칙 엔진 상세

적용 규격 배경

규칙 엔진은 항공우주 기술 문서에 널리 적용되는 3대 국제 규격을 분석하여 구축하였습니다. 세 규격은 각각 작성 명확성, 문서 구조, 매뉴얼 서식을 담당하여 기술 문서 전반을 커버합니다.

대표 규칙 예시

자주 검출되는 규칙 세 가지를 소개합니다.

STE-3.1 절차문 길이 제한 (20단어)

ASD-STE100은 절차문을 20단어 이하로 작성하도록 규정합니다. 긴 문장은 번역 오류를 유발하고 현장 작업자의 이해도를 떨어뜨립니다.

원문: "Before you start the installation procedure, make sure that all the safety pins are removed and the access panels are open and secured in the up position." — 29단어, 초과
개선: "Remove all safety pins. Open the access panels and secure them in the up position. Start the installation procedure." — 각 10단어 이하

Custom 번호 연속성 검사

섹션 번호가 건너뛰거나(1.1 → 1.2 → 1.4) 계층이 갑자기 변경되는(3.2.1 → 3.3) 오류를 감지합니다. 기술 문서에서 번호 누락은 교차참조 오류로 이어집니다.

검출: "3.1 → 3.2 → 3.4" — 오류: 번호 3.3 누락

38-A1 약어 첫 사용 시 풀네임 정의

MIL-STD-961E(4.6.3)와 MIL-STD-38784B(4.8)의 공통 요구사항입니다. 약어를 처음 사용할 때 풀네임을 함께 표기해야 하며, 미정의 약어는 경고로 분류됩니다.

검출: "The FCS shall comply with..." — 경고: FCS 풀네임 미정의

폐쇄망 환경 제약: 형태소 분석, 품사 태깅 등 대규모 NLP 모델을 상시 운용하기 어려운 환경 특성상, NLP 의존 규칙 18개(문맥 기반 용어 선택, 동사 형태 판별 등)와 주관적 판단 규칙 10개는 현 단계에서 제외하였습니다. 향후 NLP 인프라 확충 시 단계적으로 추가할 수 있습니다.

품질 스코어링

검출된 이슈의 밀도(100단어당 가중 이슈 수)를 기반으로 문서 품질을 수치화합니다. Acrolinx의 밀도 기반 스코어링 방식을 채택하였습니다.

등급 점수 판정
A 90 – 100 우수 — 출판 가능 수준
B 70 – 89 양호 — 경미한 수정 후 승인 가능
C 50 – 69 보통 — 상당한 수정 필요
D 0 – 49 미흡 — 전면 재검토 권장

이슈 심각도에 따라 가중치가 다릅니다. 오류(error)는 5, 경고(warning)는 2, 제안(suggestion)은 1이며, 규칙 신뢰도(confidence)를 곱하여 최종 밀도를 산출합니다. 오류 항목을 우선 해결하는 것이 점수 개선에 가장 효과적입니다.
