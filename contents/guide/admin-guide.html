System Administration

플랫폼 관리자 가이드

관리자(admin) 권한으로 수행하는 콘텐츠 등록, 메뉴 편집, 시스템 설정, 계정 관리 방법을 안내합니다.

콘텐츠 관리 메뉴 편집 시스템 설정 계정 관리

플랫폼은 3단계 권한 체계로 운영됩니다. 관리자(admin)는 모든 기능에 접근할 수 있으며, 편집자(editor)는 콘텐츠 편집과 업로드, 열람자(viewer)는 문서 조회만 가능합니다.

역할 권한 주요 기능
admin 전체 관리 콘텐츠 등록, 메뉴 편집, 시스템 설정, 계정 관리, 인덱스 재생성
editor 콘텐츠 편집 문서 편집, 파일 업로드
viewer 조회 전용 문서 탐색, 검색, AI 채팅, 북마크

콘텐츠 관리

콘텐츠 업로드

Explorer 좌측 트리 메뉴에서 업로드 버튼을 클릭하여 콘텐츠를 등록합니다. DOCX, PDF, Markdown, HTML 파일을 지원하며, 업로드 후 자동으로 HTML 변환과 검색 인덱스 생성이 진행됩니다.

단계 처리 내용
1. 파일 선택 트리 메뉴의 업로드 버튼 클릭 → 파일 선택 대화상자
2. 변환 DOCX → HTML 변환 (표, 수식, 이미지 포함). PDF/MD는 직접 등록.
3. 인덱싱 키워드(BM25) 인덱스 생성. 벡터(FAISS) 인덱스는 설정에 따라 자동 실행.
4. 메뉴 등록 트리 메뉴에 항목이 추가되어 전체 사용자에게 즉시 반영.

검색 인덱스 관리

Explorer 좌측 패널 하단의 상태 표시줄에서 인덱스 상태를 확인합니다. "갱신 필요" 표시 시 재생성 버튼을 클릭하면 키워드 및 벡터 인덱스가 갱신됩니다. 업로드 설정에서 자동 재생성을 활성화하면 콘텐츠 등록 시 자동으로 처리됩니다.

인라인 편집

Explorer 상단 Edit 메뉴를 클릭하면 현재 문서를 직접 편집할 수 있습니다. 자동 저장 간격과 백업 생성 여부는 시스템 설정에서 조정합니다.

메뉴 편집

Explorer 상단 Edit 메뉴에서 메뉴 편집 모드로 진입합니다. 트리 구조의 메뉴 항목을 추가, 이름 변경, 삭제, 순서 변경할 수 있으며, 드래그앤드롭으로 계층 구조를 재구성합니다. 변경사항은 저장 즉시 전체 사용자에게 반영됩니다.

기능 설명
항목 추가 카테고리(폴더) 또는 문서 링크를 추가합니다.
이름 변경 메뉴 항목의 표시 이름을 수정합니다.
순서 변경 드래그앤드롭으로 항목 순서와 계층을 조정합니다.
삭제 메뉴 항목을 제거합니다. 시스템 보호 항목(플랫폼 가이드 등)은 삭제할 수 없습니다.

시스템 설정

런처 또는 헤더의 시스템 전환 버튼에서 관리자 설정 페이지에 접근합니다. 설정은 시스템별, 탭별로 구분되어 있으며 변경 후 저장 버튼을 클릭합니다. 일부 항목은 서버 재시작이 필요하며, 해당 항목에는 안내가 표시됩니다.

AI / RAG 설정

항목 설명
Ollama URL 로컬 Ollama 서버 주소 (예: http://localhost:11434). 재시작 필요.
LLM 모델 채팅에 사용할 모델 이름 (예: gemma3:4b). 재시작 필요.
임베딩 모델 벡터 검색용 모델 (예: bge-m3). 재시작 필요.
기본 검색 방식 hybrid(권장), keyword, vector 중 선택.
최대 검색 결과 챗봇 응답에 사용할 최대 문서 청크 수 (1~20).
최대 컨텍스트 길이 LLM에 전달할 최대 문자 수 (1,000~32,000).
리랭커 교차 인코더 리랭커(bge-reranker-v2-m3) 활성화 여부.
쿼리 재작성 멀티턴 대화에서 후속 질문을 독립 쿼리로 자동 변환.
시스템 프롬프트 RAG 챗봇의 기본 응답 지침.

세션 설정

항목 설명
최대 대화 턴 챗봇이 기억하는 최대 Q&A 쌍 수 (1~20).
최대 히스토리 길이 LLM에 전달할 대화 이력 최대 문자 수.
최대 세션 수 서버 메모리에 유지할 동시 세션 수. 초과 시 LRU 방식으로 제거.
유휴 타임아웃 비활성 세션 자동 삭제 시간 (분).
로그인 유지 시간 로그인 세션 유효 시간 (시간 단위). 재시작 필요.

업로드 설정

항목 설명
업로드 활성화 편집자 이상 사용자에게 업로드 UI 표시 여부.
최대 파일 크기 단일 파일 최대 크기 (MB).
자동 키워드 인덱싱 업로드 후 BM25 검색 인덱스 자동 재생성.
자동 벡터 인덱싱 업로드 후 FAISS 벡터 인덱스 자동 재생성. 시간 소요가 큽니다.
DOCX COM 전처리 Microsoft Word COM으로 자동 번호를 평문화. Windows + Word 설치 필요.

화면 / 에디터 설정

항목 설명
사이트 제목 헤더, 로그인 페이지, 브라우저 탭에 표시되는 사이트 이름.
테이블 스타일 bordered(기본), simple, minimal 중 선택.
AI 챗봇 표시 우하단 AI 채팅 버튼 표시 여부.
에디터 활성화 인라인 문서 편집 기능 사용 여부.
자동 저장 간격 편집 시 자동 저장 주기 (밀리초 단위, 기본 30초).
백업 생성 저장 전 .bak 백업 파일 생성 여부.

보안 설정

항목 설명
로그인 필수 비인증 API 접근 차단 여부. 재시작 필요.
CORS 허용 출처 허용할 외부 도메인 목록 (줄바꿈 구분). 재시작 필요.

Notebook / Verify 설정

Notebook과 Verify 시스템별 설정은 관리자 설정 페이지에서 해당 시스템 탭을 선택하여 조정합니다.

시스템 설정 영역 주요 항목
Notebook 번역 모델 Notebook 전용 Ollama 모델 지정 (미지정 시 Explorer 모델 사용)
PDF 번역 품질 번역 프롬프트, 표 텍스트 번역, OCR, 최소 텍스트 길이
웹뷰 번역 품질 표 처리 방식, 수식 처리, 이미지 DPI, 자동 요약
Verify 비교 설정 AI 의미 분류 활성화, 온도, 배치 크기, 타임아웃
유사도 설정 유사도 임계값(높음/중간), 판정 기준, Winnowing 파라미터
재시작 필요 항목: Ollama URL, LLM 모델, 임베딩 모델, 로그인 필수, CORS, 로그인 유지 시간은 변경 후 서버 재시작이 필요합니다. 해당 항목 변경 시 UI에 안내가 표시됩니다.

계정 관리

관리자 설정 페이지의 "계정 관리" 탭에서 사용자를 관리합니다.

기능 설명
사용자 목록 등록된 전체 사용자의 ID, 역할, 생성일을 확인합니다.
사용자 추가 사용자명, 비밀번호, 역할(viewer/editor/admin)을 입력하여 등록합니다.
정보 수정 비밀번호 변경, 역할 변경이 가능합니다.
사용자 삭제 확인 후 삭제됩니다. 자기 자신은 삭제할 수 없습니다.

초기 운영 시 관리자 계정을 설정한 뒤, 팀별로 viewer 계정을 배포하여 운용합니다. 편집 권한이 필요한 담당자에게는 editor 역할을 부여합니다.

참고: 설정 변경은 저장 즉시 적용됩니다 (재시작 필요 항목 제외). 설정 초기화가 필요한 경우 data/settings.json 파일을 삭제하면 기본값으로 복원됩니다.
