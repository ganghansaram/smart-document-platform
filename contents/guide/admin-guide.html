System Administration

플랫폼 관리자 가이드

관리자(admin) 권한으로 수행하는 콘텐츠 등록, 메뉴 편집, 시스템 설정, 계정 관리 방법을 안내합니다.

콘텐츠 관리 메뉴 편집 시스템 설정 계정 관리

플랫폼은 3단계 권한 체계로 운영됩니다. 관리자(admin)는 모든 기능에 접근할 수 있으며, 편집자(editor)는 콘텐츠 편집과 업로드, 열람자(viewer)는 문서 조회만 가능합니다.

역할 권한 주요 기능
admin 전체 관리 콘텐츠 등록, 메뉴 편집, 시스템 설정, 계정 관리, 인덱스 재생성
editor 콘텐츠 편집 문서 편집, 파일 업로드
viewer 조회 전용 문서 탐색, 검색, AI 채팅, 북마크

콘텐츠 관리

콘텐츠 업로드

Explorer 좌측 트리 메뉴에서 업로드 버튼을 클릭하여 콘텐츠를 등록합니다. DOCX, PDF, Markdown, HTML 파일을 지원하며, 업로드 후 자동으로 HTML 변환과 검색 인덱스 생성이 진행됩니다.

단계 처리 내용
1. 파일 선택 트리 메뉴의 업로드 버튼 클릭 → 파일 선택 대화상자
2. 변환 DOCX → HTML 변환 (표, 수식, 이미지 포함). PDF/MD는 직접 등록.
3. 인덱싱 키워드(BM25) 인덱스 생성. 벡터(FAISS) 인덱스는 설정에 따라 자동 실행.
4. 메뉴 등록 트리 메뉴에 항목이 추가되어 전체 사용자에게 즉시 반영.

검색 인덱스 관리

Explorer 좌측 패널 하단의 상태 표시줄에서 인덱스 상태를 확인합니다. "갱신 필요" 표시 시 재생성 버튼을 클릭하면 키워드 및 벡터 인덱스가 갱신됩니다. 업로드 설정에서 자동 재생성을 활성화하면 콘텐츠 등록 시 자동으로 처리됩니다.

인라인 편집

Explorer 상단 Edit 메뉴를 클릭하면 현재 문서를 직접 편집할 수 있습니다. 자동 저장 간격과 백업 생성 여부는 시스템 설정에서 조정합니다.

메뉴 편집

Explorer 상단 Edit 메뉴에서 메뉴 편집 모드로 진입합니다. 트리 구조의 메뉴 항목을 추가, 이름 변경, 삭제, 순서 변경할 수 있으며, 드래그앤드롭으로 계층 구조를 재구성합니다. 변경사항은 저장 즉시 전체 사용자에게 반영됩니다.

기능 설명
항목 추가 카테고리(폴더) 또는 문서 링크를 추가합니다.
이름 변경 메뉴 항목의 표시 이름을 수정합니다.
순서 변경 드래그앤드롭으로 항목 순서와 계층을 조정합니다.
삭제 메뉴 항목을 제거합니다. 시스템 보호 항목(플랫폼 가이드 등)은 삭제할 수 없습니다.

시스템 설정

런처 또는 헤더의 시스템 전환 버튼에서 관리자 설정 페이지에 접근합니다. 사이드바는 관리(계정 관리, 대시보드)와 플랫폼 설정(일반, AI 연결, 콘텐츠, 검색/챗봇, 번역, 문서 검증) 두 그룹으로 구분됩니다. 변경 후 저장 버튼을 클릭하며, 일부 항목은 서버 재시작이 필요합니다. 자주 변경하지 않는 세부 항목은 [고급] 섹션에 접혀 있습니다.

일반

항목 설명
사이트 타이틀 헤더, 로그인 페이지, 브라우저 탭에 표시되는 사이트 이름.
테이블 스타일 bordered(기본), simple, minimal 중 선택.
열람 로그인 필수 비인증 사용자의 접근 차단 여부. 재시작 필요.
로그인 세션 만료 로그인 유지 시간 (시간 단위). 재시작 필요.
에디터 활성화 인라인 문서 편집 기능 사용 여부.
저장 시 백업 생성 파일 저장 전 .bak 백업 파일 생성 여부.

[고급] 섹션: 자동 저장 간격, 최대 대화 턴 수, 유휴 세션 만료

AI 연결

항목 설명
Ollama URL Ollama 서버 주소 (예: http://localhost:11434). 재시작 필요. Docker 환경에서는 .env로 관리됩니다.
AI 모델 플랫폼 전체에서 사용하는 기본 AI 모델 (예: gemma3:4b). Explorer 챗봇, Notebook 번역/요약, Verify 비교에 모두 적용. 재시작 필요.
AI 챗봇 표시 Explorer 우측 하단 AI 챗봇 버튼 표시 여부.

콘텐츠

업로드 탭과 메뉴 관리 탭으로 구분됩니다.

항목 (업로드 탭) 설명
업로드 기능 활성화 편집자 이상 사용자에게 업로드 UI 표시 여부.
최대 파일 크기 단일 파일 최대 크기 (MB).
검색 인덱스 자동 갱신 업로드 후 BM25 검색 인덱스 자동 재생성.
벡터 인덱스 자동 갱신 업로드 후 FAISS 벡터 인덱스 자동 재생성. 시간 소요가 큽니다.

검색 / 챗봇

항목 설명
검색 방식 하이브리드(권장), 키워드(BM25), 벡터 유사도 중 선택.
최대 검색 결과 수 챗봇 응답에 사용할 최대 문서 청크 수 (1~20).
리랭커 사용 교차 인코더 리랭커로 검색 결과 정확도 향상.
쿼리 재작성 멀티턴 대화에서 후속 질문을 독립 쿼리로 자동 변환.
시스템 프롬프트 RAG 챗봇의 기본 응답 지침. 비워두면 기본 프롬프트 적용.

[고급] 섹션: 최대 컨텍스트 길이, 키워드 비중, 최소 벡터 유사도

번역

항목 설명
테이블 텍스트 번역 PDF 번역 시 표 안의 텍스트도 번역 대상에 포함.
OCR 우회 스캔 PDF에서 OCR 처리 활성화.
표 추출 모드 웹뷰 번역 시 표 영역 처리 방식 (구조 추출/이미지/끄기).
수식 추출 모드 웹뷰 번역 시 수식 처리 방식 (LaTeX/이미지/끄기).
자동 요약 전체 추출 완료 후 AI 요약 자동 생성 여부.
동시 번역 수 서버에서 동시에 처리할 최대 번역 작업 수.

[고급] 섹션: 번역 모델 오버라이드, 커스텀 프롬프트, 리치텍스트 비활성화, 호환성 강화, 이미지 DPI, 페이지 타임아웃, AI 번역/요약 프롬프트

문서 검증

AI 비교, 유사도 검사, 규칙 검증 세 개 탭으로 구분됩니다.

탭 항목 설명
AI 비교 AI 비교 활성화 차이점의 AI 의미 분류 기능 사용 여부
시스템 프롬프트 AI 비교 분류 지침. [고급]: 모델 오버라이드, 온도
유사도 검사 유사도 임계값 높음/중간 기준 (0~100%)
판정 기준 낮음/높음 판정 경계값
규칙 검증 규칙 편집기 검증 규칙 목록 관리 (추가, 편집, 삭제, 활성화 토글)
재시작 필요 항목: Ollama URL, AI 모델, 열람 로그인 필수, 로그인 세션 만료는 변경 후 서버 재시작이 필요합니다. 해당 항목 변경 시 UI에 안내가 표시됩니다. Docker 환경에서는 Ollama URL과 AI 모델이 .env 환경변수로 관리되며, 설정 UI에서 변경할 수 없습니다.

계정 관리

관리자 설정 페이지의 "계정 관리" 탭에서 사용자를 관리합니다.

기능 설명
사용자 목록 등록된 전체 사용자의 ID, 역할, 생성일을 확인합니다.
사용자 추가 사용자명, 비밀번호, 역할(viewer/editor/admin)을 입력하여 등록합니다.
정보 수정 비밀번호 변경, 역할 변경이 가능합니다.
사용자 삭제 확인 후 삭제됩니다. 자기 자신은 삭제할 수 없습니다.

초기 운영 시 관리자 계정을 설정한 뒤, 팀별로 viewer 계정을 배포하여 운용합니다. 편집 권한이 필요한 담당자에게는 editor 역할을 부여합니다.

참고: 설정 변경은 저장 즉시 적용됩니다 (재시작 필요 항목 제외). 설정 초기화가 필요한 경우 data/settings.json 파일을 삭제하면 기본값으로 복원됩니다.
