| 스팟 | 규칙 | 라이트 | 다크 |

색 출처: `--color-warning`(주황) / `--active-color`(파랑) / `--color-success-btn`(초록), 각 `10%`(라이트)·`12%`(다크) 틴트 배경 + 풀채도 아이콘/텍스트.

**⚠️ 경계 — 건드리면 안 되는 색 (별개 시스템):**
`--color-warning` 은 **유사도 분류 체계**에서도 쓰임 — `.sim-*-near_copy`(1351~), `.sim-verdict-*`(1491~), `.sim-cat-*`·`.sim-ind-*`·`.sim-filter-chip-*` 등. 이건 CLAUDE.md "유사도 분류 체계"의 **기능 색**(동일/거의동일/의역)이라 **반드시 보존.** 토큰(`--color-warning`)은 그대로 두고, **`.type-*` 6개 규칙군의 색 선언만** 모노크롬으로 교체한다(token 미변경 → sim-* 무영향).

## 3. 결정 사항
1. **색 = 장식, 라벨 = 정보** — 텍스트가 이미 모드 구분 → 색 제거해도 기능 무손실. Plan-62 "기능적 색코딩" 전제를 번복(근거 명시).
2. **두 스팟 동시** — 허브 아이콘만 바꾸고 최근작업 배지를 3색으로 두면 더 부정합. 반드시 함께.
3. **유사도 분류색 불가침** — `--color-warning` 토큰 미변경, `.type-*` 규칙만 수정. `sim-*` 회귀 0 확인 필수.
4. **방향은 시안 택1** (권장 C) — 착수 전 확정.
