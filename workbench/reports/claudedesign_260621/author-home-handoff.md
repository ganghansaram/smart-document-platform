## 1. 이 시안의 성격 (중요)
- 시안은 **Design Component(`.dc.html`) 포맷의 비주얼 스펙**이다. 우리 실제 스택은 **바닐라 JS + CSS 클래스**(Explorer/Verify와 동일).
- 따라서 구현은 시안을 그대로 쓰는 게 아니라, **Plan-61의 파일 계획대로 이식**한다:
  - `author.html` (셸 + 본문 골격)
  - `css/author.css` (시안의 **인라인 스타일 → 클래스로 이식**, 토큰 변수 소비)
  - `js/author.js` (셸 로직·인증·테마·목록 렌더·뷰 토글)
- 시안의 인라인 `style="..."`는 **그대로 복붙하지 말고** 의미 단위로 `author.css` 클래스화한다. 값은 전부 `tokens.css` 변수에서 온 것이라 클래스로 옮겨도 1:1 매핑된다.

## 2. 절대 규칙 (CLAUDE.md 정합)
- **`tokens.css` 변수만 소비.** 색·간격·둥글기·그림자 하드코딩 0. 시안에 박힌 리터럴(예: `rgba(...)`, `6px`)은 대응 토큰(`--active-color-subtle`, `--space-*`, `--radius-*`, `--shadow-*`)으로 치환.
- **헤더는 실제 컴포넌트 재사용.** `platform-header.css` 클래스 + `initPlatformHeader({ currentSystem:'author' })`. 시안의 헤더 마크업은 참고용 복제일 뿐.
- **아이콘 = 인라인 라인 SVG**(stroke=currentColor). 이모지 금지.
- **상태 신호는 진입점 1곳만.** "개발 예정" 뱃지는 합성 *진입 타일*에만. 다색(무지개) 상태칩 금지.
- **다크모드는 토큰이 자동 처리** — 다크 색을 직접 적지 않는다. 테마 토글은 `document.body[data-theme]`만 스왑.

## 3. 화면 구조 (위→아래)
```
[플랫폼 헤더: Author · 시스템 스위처 · 사용자 · 테마토글]
[이어서 작업 바]            ← 마지막 편집 문서 1건 resume (선택)
[새로 만들기]
  ┌ 빈 문서 작성 ┐  ┌ 합성 프로젝트 [개발 예정] ┐   ← 진입 타일 2개(패널 그림자)
[최근 문서]   [카드|리스트 토글] [+ 새 문서] [전체 보기]
  카드 3열  /  리스트(문서명·작성자·수정일)
[합성 프로젝트]              [+ 새 합성] [전체 보기]
  카드 3열 (소스 핀 + 비교 매트릭스 미니바)
```

## 4. 데이터: 목 vs 실연동
| 영역 | 처리 |
|------|------|
| 최근 문서 | **실연동** — `GET /api/authored` (front matter title·author, 최신순). 클릭 → `index.html`로 보내 해당 `.md` 열람(읽기는 Explorer). |
| 합성 프로젝트 카드 | **목(미리보기)** — 백엔드(`/api/author/*`) 미구현. 레이아웃 참조용. 실제론 빈 상태/empty-first로 시작. |
| 이어서 작업 바 | 목. 최근 편집 1건을 보여주는 자리표시. |
| 진입 타일 액션 | 현재는 "곧 제공" 안내(자리표시). 실연결은 후속 Phase(Strangler). |

## 5. 상태(prop) 동작 — `js/author.js`로 옮길 분기
시안은 3개 prop으로 분기한다. 구현 시 동일 로직을 셸 로직/조건부 렌더로:
- `synthesisStatus`: `available | beta | hidden`
  - `beta`(기본): 합성 진입 타일에 **"개발 예정"** 뱃지(브랜드 블루 = `--active-color`). 런처 카드 관례와 일치.
  - `available`: 뱃지 없음(정식). 그 외 레이아웃 동일.
  - `hidden`: 합성 진입 타일 + 합성 섹션 숨김.
- `defaultView`: `cards | list` — 최근 문서 초기 뷰.
- `showResume`: `boolean` — 이어서 작업 바 노출.

## 6. 상태칩 정책 (의도적으로 절제됨)
- **작성 문서엔 상태칩 없음.** 플랫폼에 발행/배포 개념이 없다(작성 → 저장 → DOCX 내보내 워드에서 다듬어 제출). "발행됨/검토중" 같은 필드는 존재하지 않으므로 만들지 말 것. 카드 = `제목 · 작성자 · 수정일`.
- **합성 카드만 단계칩 1종(단색).** 합성은 실제 라이프사이클(소스→추출→매트릭스→선별→AI 초안)이 있어 `선별 중`/`초안 생성됨` 같은 단계 표시 정당. 단 **단색(브랜드 악센트)**, 무지개 금지.
- 합성 카드의 **매트릭스 미니바**(초록/노랑/빨강/회색)는 "상태"가 아니라 *공통/부분/충돌/단일 분포* 데이터 시각화 → 시맨틱 토큰(`--color-success/warning/error`, `--text-muted`) 사용, 유지.

## 7. 반응형·접근성
- `@media(max-width:880px)`: 진입 타일 2열→1열, 카드 그리드 3열→2열(560px 이하 1열).
- 헤딩 시맨틱(h1 헤더 / h3 섹션), 테마토글·스위처 `aria-label`, 키보드 포커스 링은 `tokens.css :focus-visible` 유지.
