## 1. 🔴 Critical — 동작 모델 재해석 필요

### 1.1 수동 제외는 "가시성 이동"이 아니라 "점수 + 가시성 동시 영향"

**현재 코드 (`compare.html:1427-1442`)**:
```js
if (m.user_excluded) {
    userExcludedSpan += sc;  // 점수 분모에서 차감
    continue;
}
excludedCount += userExcludedSpan;  // 제외 영역 카운트에 합산
```

즉 사용자가 ⓧ로 제외하면 **점수 분모가 줄어** 유사율이 변화한다. 이는 Plan-38 의도된 동작 (수동 제외 = "이건 표절 아님 → 점수에서 빼기").

**Plan-45 §4.3 현재 문구**:
> "표시 필터 = 단일 가시성 게이트 / 점수 산출에 영향 없음"

이 표현이 **표시 필터와 수동 제외를 혼동**시킨다. 정정 필요:

| 동작 | 점수 | 가시성 | 비고 |
|---|---|---|---|
| 검사 설정 (☑정형구문 제외 등) | ✅ 영향 | ❌ 영향 X (해당 유형 카드가 별도로 있는 경우에만) | `simRecomputeFromSettings` |
| 표시 필터 (4그룹 체크박스) | ❌ 영향 X | ✅ 영향 | `simApplyFilter` |
| 수동 제외 (카드 ⓧ) | ✅ 영향 | ✅ 영향 ("제외 영역" 그룹으로 이동 → 필터에 따름) | `simApplyUserExclusion` → 양쪽 호출 |

**권고**: 계획서 §4.3을 "표시 필터"에 대한 규칙으로 한정하고, 수동 제외의 이중 효과를 §4.4 또는 Phase 5에 별도 명시. 점수 재계산 경로는 **보존** (기존 Plan-38 동작 유지).

## 2. 🟡 Warning — 계획서 레이아웃 모의 수정

### 2.1 "일반" 필터 칩 제거

§6.1 사이드바 수직 구성 mockup:
```
☑ 🔴 표절 의심 (147)
☑ 🟡 참고 가능 (47)
☐ ⚪ 제외 영역 (0)
☐ ⚫ 일반          ← 무의미
```

**문제**: "일반"은 매칭이 없는 문장 그룹. **매칭 카드가 존재하지 않으므로 필터 체크박스가 토글할 대상이 없다.**

**권고**: 필터 칩은 **3개만** (표절 의심 / 참고 가능 / 제외 영역). "일반"은 누적바 + 그룹 라벨에만 표시 (읽기 전용 통계).

### 2.2 필터 칩 카운트 = 누적바 그룹 카운트

§6.1 mockup: `☑ 🔴 표절 의심 (147)` — 이 숫자의 정의 미명시.

**권고**: 필터 칩 카운트 = 해당 그룹의 **현재 매칭 수**(수동 제외 반영 후). 즉 `simRecomputeFromSettings()`의 `suspectN/reviewN/excludedN` 값과 동일. 점수·누적바·필터 칩 카운트가 **항상 일치**해야 함 (진실의 원천 1개).

## 3. 🟡 Warning — 누락된 렌더 경로

### 3.1 본문 하이라이트(`.sim-hl-*`)의 4그룹 색상 미지원

현재 `css/compare.css:1596-1600`:
```css
.sim-hl-identical   { background: var(--sim-identical); ... }
.sim-hl-near_copy   { background: var(--sim-near-copy); ... }
.sim-hl-paraphrase  { background: var(--sim-paraphrase); ... }
.sim-hl-low_sim     { background: var(--sim-low); ... }
.sim-hl-boilerplate { background: var(--sim-boilerplate); ... }
```

**문제**: 본문 하이라이트 색상은 **6세부 기준**인데, 사이드바 카드 도트는 Plan-45에서 **4그룹 기준**. 한 화면에서 두 색상 체계 충돌 가능.

**권고 (택 1)**:
- **A안 (단순)**: 본문 하이라이트도 4그룹 색상으로 통일. 빨강/노랑/회색 3종만.
- **B안 (정보량 우선)**: 본문은 6세부 유지, 사이드바 카드 도트도 6세부 색상 + 4그룹 테두리.

§6.1/§6.3에 선택 명시 필요. (의견: A안 — 축이 하나면 혼동 없음. 6세부 구분은 카드 텍스트로 충분.)

### 3.2 미니맵 마커 색상

`compare.html:3031` 현재:
```js
var colorVar = 'var(--sim-' + type.replace('_', '-') + '-border, var(--color-info))';
```
→ 6세부 색상. 본문 하이라이트와 동일 정책 필요. §3.1과 묶어 일관 처리.

### 3.3 수동 제외 하이라이트 클래스 `sim-hl-user-excluded`

`compare.html:2809`:
```js
highlightEls[hi].classList.toggle('sim-hl-user-excluded', !!excluded);
```

그리고 `css/compare.css:1458`에 대응 스타일 존재. Plan-45 §4.3 "보이거나 안 보이거나 둘 중 하나" 원칙 적용 시 **이 클래스의 반투명 효과도 제거** 필요. 보이면 원래 하이라이트, 숨기면 display:none.

Phase 5 작업 항목에 명시 권고.

### 3.4 HTML 리포트 export의 그룹 분류

`compare.html:4987-4992` TYPE_META 배열:
```js
{ key: 'boilerplate', group: '제외 영역', label: '정형구문' }  // ← "공통 정형구문"이어야
```

**권고**: Phase 3.5에서 이미 "정형구문" → "공통 정형구문" 교체 예정. 추가로 **수동 제외 항목은 원래 type과 무관하게 "제외 영역" 그룹 섹션에 배치**하는 로직도 Phase 3.5에 추가 필요 (현재 L5075~5095는 원래 type 그룹에 배치).

## 4. 🟡 Warning — 엣지 케이스

### 4.1 수동 제외 직후 네비게이션(↑↓) 동작

현재 네비게이션은 `simGetVisibleMatches()`(DOM display 기반)를 참조. 사용자가 현재 활성(`simActiveIdx`) 매칭을 ⓧ 제외 → 카드 display:none → `visible` 배열에서 사라짐 → `simActiveIdx`는 무효 인덱스.

**권고**: `simApplyUserExclusion`에서 `simActiveIdx === excludedIdx`이면 다음 visible 매칭으로 자동 이동 (또는 -1 리셋). Phase 5 항목에 명시.

### 4.2 필터 OFF 상태에서의 빈 화면

`compare.html:2534`: 빈 상태는 `matches.length === 0`에서만 노출. 사용자가 3그룹 모두 OFF → 사이드바 비어있지만 안내 없음.

**권고**: Phase 2에 "필터로 모든 매칭이 숨겨졌을 때 전용 빈 상태" 추가:
```
[ 👁 숨김 아이콘 ]
표시 필터가 모두 꺼져 있습니다
필터 하나 이상을 켜서 결과를 확인하세요
```

### 4.3 수동 제외 반복 — toast 중첩

Phase 5: 5초 toast "[복원]". 사용자가 5초 이내에 여러 건 제외 시?

**권고**: toast는 "최근 1건"만 표시 (기존 toast 대체). 복원 버튼은 최근 제외 1건만 대상. 과거 건 복원은 "제외 영역" 필터 ON → 배너 복원 버튼으로.

### 4.4 수동 제외 상태의 세션 간 유실

`simLastResult`는 메모리에만 존재. 페이지 새로고침 시 모든 `user_excluded` 상태 유실. Plan-45 범위는 아니지만 사용자가 기대 위반 가능성.

**권고**: Open Question으로 §12에 추가. 범위 외 판단 시 문서에 명시("수동 제외는 세션 내 유지, 재검사 시 초기화 — 향후 Plan").

## 6. ⚪ Note — 보조 개선 (우선순위 낮음)

### 6.1 DETECTION_LAYER 카드 노출

Plan-38 §8.1: "기본 숨김, 고급 설정에서만". Plan-45 §12 Open Q#4에 남겨둠. **현재도 카드에 "텍스트 매칭 / AI 분석" 노출 중**. 라벨 체계 단일화와는 독립적이나, 사용자가 "낯선 용어"로 지목할 가능성 있음.

**권고**: Phase 2에 함께 처리 — 카드에서 제거, 카드 hover 툴팁으로 이동. 비용 낮고 인지 부하 추가 감소.

### 6.2 접근성 (aria-label)

필터 칩 `<label>`에 aria-label 명시. 🔴🟡⚪ 도트는 장식 요소이므로 `aria-hidden="true"`. 체크박스 상태 변화 시 `aria-live="polite"` 영역에 "표절 의심 숨김" 공지 (선택적).

**권고**: Phase 4 시각 분리 작업 시 동반 적용.

### 6.3 색각 이상(CVD) 고려

4그룹 색상: 🔴(빨) 🟡(노) ⚪(회) ⚫(검). 빨-노 인접성이 CVD 사용자에게 약점. 도트 외에 **패턴(실선/점선)** 또는 **아이콘(경고/눈/정지)** 병용 권장.

**권고**: 현 단계에서는 보류 (디자인 시스템 차원 과제). Plan-45 §13에 노트로 추가.

### 6.4 @media print 가시성

Plan-45 §9.3에 체크 항목만 있음. 구현 위치 명시 필요.

**권고**: Phase 4에 `@media print { .sim-check-settings, .sim-filter-block { display:none; } }` 명시.
