## 3. P0/P1 이슈 수정 방향 제안

### P0-1: 검증 점수 과도 가혹

**현재**: DENSITY_THRESHOLD = 5.0, 경고(×2) 13건 → 밀도 8.52 → 0점

**방안 A — 임계값 상향** (최소 침습):
- `DENSITY_THRESHOLD = 10.0`으로 조정
- 같은 케이스: 밀도 8.52 / 10.0 = 0.852 → score = 15점 (D)
- 여전히 낮지만 0점은 아님

**방안 B — 가중치 조정** (권장):
- warning: 2 → 1.5, suggestion: 1 → 0.5
- 같은 케이스: 13×1.5 + 4×0.5 = 21.5, 밀도 = 6.11 → 0점 (여전히 부족)

**방안 C — 밀도+등급 분리** (가장 효과적):
- `DENSITY_THRESHOLD = 10.0` + warning 가중치 1.5
- 같은 케이스: 21.5 / 3.52 = 6.11 / 10.0 → score = 39점 (D)
- 추가: 등급 D 기준을 50점 미만으로 하향 (60→50)

**방안 D — 로그 스케일** (업계 표준):
- `score = 100 × (1 / (1 + density/k))` (시그모이드 유사)
- k=3: 밀도 8.52 → score = 26점, k=5: 밀도 8.52 → score = 37점
- 장점: 밀도가 높아져도 0점에 수렴하지 않음, 변별력 유지

### P0-2: TYPE_TRANSLATION 부재

`_classify_match()`에 언어 감지 분기 추가:
```python
# 언어가 다르고 sem_score >= th_high → TYPE_TRANSLATION
if detected_lang_target != detected_lang_ref and sem_score >= th_high:
    return TYPE_TRANSLATION
```
또는 간이 방식: fp_score < 0.10 (완전 다른 문자셋) + sem_score >= th_high → translation.

### P1-1: Paraphrase dead zone

`_classify_match()` 조건 완화:
```python
# 기존: fp < 0.15 and sem >= 0.88
# 개선: fp < 0.40 and sem >= th_high
if fp_score < 0.40 and sem_score >= th_high:
    return TYPE_PARAPHRASE
```
L295 (near_copy: fp>=0.40)와 배타적이므로 충돌 없음.

### P1-7: 약어 오탐

common_abbrs 화이트리스트에 도메인 약어 추가:
`EMC, EUT, LISN, KAI, KF, AC, DC, Hz, kHz, MHz, GHz` 등.
또는 관리자 설정 UI에서 화이트리스트 편집 기능 제공.
