## 1. 사용자 입장 — 시각 인지 회복

### Before (Plan-55 까지)
검사 후 본문 패널에:
- `## 1.1 검증 범위` ← markdown 기호 그대로 노출
- `## 참고문헌` ← markdown 기호 그대로 노출
- 사용자: "이게 뭐지? 도구가 깨졌나?"

### After (Plan-56 적용)
- "1." → 큰 글씨 H1 (시각 위계 명확)
- "1.1 검증 범위" → 중간 글씨 H2 + 회색 (자동 제외)
- "참고문헌" → 중간 글씨 H2 (매칭 자체 없음)
- ASTM/ISO 항목 → 일반 글씨 (참고문헌 자동 제외라 매칭 없음)

→ **`##` 기호 노출 0건, 시각 위계 회복**. 사용자 페인 직접 해소.

## 3. UX 전문가 입장 — 시각 위계 + 자동 제외 통합

### 시각 위계 회복
- H1: 큰 글씨 (CSS `.sim-md-view h1` 정의 — `--font-title`, 하단 border)
- H2: 중간 글씨 (`--font-title` 동일, hint border)
- H3: 작은 글씨 (`--font-body`)
- 본문 P: 일반 본문 글씨

→ DOCX 의 Heading 1/2/3 시각 위계가 그대로 보존.

### Plan-54 (자동 제외 시각 신호) 와 통합
- 자동 제외된 헤딩 (`## 1.1 검증 범위` 등) → 회색 + 점선 (paragraph 룰) 또는 셀 단위 회색 처리 (table 룰) 와 동일 시각 패턴
- 단, `<h2>` 도 `.sim-hl.sim-hl-excluded` paragraph 룰 적용됨 (paragraph + div 한정 셀렉터인데 `<h2>` 포함되어야)
- 확인 필요: `.sim-md-view p.sim-hl.sim-hl-excluded, .sim-md-view div.sim-hl.sim-hl-excluded` — `<h2>` 미포함

### 잔여 부수 미세 결함 (UX 전문가 지적)
**Plan-54 의 `.sim-hl-excluded` 셀렉터가 `<h{1..6}>` 미포함** → 자동 제외된 헤딩이 시각 신호 (회색/흐림) 안 받음.
- 캡처에서 H1/H2 가 `sim-hl-excluded` 클래스는 부여됐지만 CSS 룰 미매칭 → 일반 헤딩 색상으로 표시
- 영향: 사용자 인지 약간 저하 (자동 제외 인식 어려움). 시각 결함 아님.
- 후속 조치: CSS 셀렉터에 `h1, h2, h3, h4, h5, h6` 추가 필요 (Plan-56 hotfix 후속)

### 첫 업로드 vs 검사 후 일관성
- 업로드 직후: simMdToHtml 의 헤딩 변환 + 인라인 마크업
- 검사 후: backend 의 헤딩 변환 + paragraph
- 두 시점 시각 위계 거의 일치 (인라인 마크업 외)
- → 사용자 인지 **연속성 회복** ✓

## 4. 점수 정확도 입장 — Inflation 해소 검증

### 시나리오: 동일 본문 + 동일 참고문헌 (학술 보고서 패턴)
- 본문 sentence 4건 (모두 의역 매칭)
- 표 행 (헤더 1 + 데이터 1)
- 참고문헌 항목 2건 (동일 ISO/ASTM 인용)

### 점수 분석
**적용 후 점수: 40%**
- 분자: 의역 2 sentence (paraphrased)
- 분모: 9 - 자동 제외 (헤딩 3 + 표 헤더 1 + 표 데이터 1 + 참고문헌 헤딩 1 + 참고문헌 항목 2 = 8?) — 실제 분모는 sentence index set 기반 정확 계산
- 결과: 40% 가 정확한 본문 비교 점수

**가상 — Plan-56 적용 안 했을 때 (참고문헌 자동 제외 실패 시)**
- 참고문헌 ASTM/ISO 항목 2건이 identical 매칭 → 분자에 포함
- 분모도 변동
- 결과: 점수 inflated (60% 등)

→ Plan-56 으로 **참고문헌 자동 제외 정상화** + **점수 정확도 회복**. 학술/공식 문서의 운영 측 점수 신뢰도 향상.

### 점수 정확도 평가
| 항목 | 평가 |
|------|------|
| 헤딩 자동 제외 (toc_heading) | ✅ 정상 |
| 참고문헌 섹션 자동 제외 (references_section) | ✅ **정상화** |
| 표 헤더 자동 제외 (table_structural) | ✅ 기존 정상 |
| 일반 본문 매칭 | ✅ 변동 없음 |
