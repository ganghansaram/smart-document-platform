# Plan-53 — 사용자 입장 테스트 피드백

> 작성일: 2026-04-30
> 작성 관점: **일반 사용자 (운영 측 검증자)** — 코드 모르는 검수자가 직접 사용해본 인상
> 테스트 환경: Plan-50 ~ Plan-53 까지 모든 적용 후 상태 (백엔드 + 프론트 통합)
> 테스트 시나리오: 항공기 부품 검증 보고서 2건 비교 (본문 의역 + 표 헤더 동일 + 표 데이터 다름)

## 1. 테스트 시나리오 — 현실 페인 재현

업무 상황을 모방한 실제적 케이스:
- **문서 A**: "이 보고서는 항공기 부품의 품질 검증 프로세스를 설명한다..." + 부품 표 (A-100, A-200) + 결론
- **문서 B**: "본 문서는 항공우주 부품 검증 절차를 다룬다..." + 부품 표 (B-300, B-400) + 결론

→ 두 문서는 **본문이 의역되어 있고 표 헤더만 같으며 표 데이터는 완전히 다름**. 사용자가 "이게 표절인지?" 판단하려는 전형적 상황.

---

## 2. 첫 인상 (1분 이내)

### 좋았음 ✅
- 두 문서 업로드 후 검사 버튼 한 번 클릭으로 결과 표시 — **3초 이내**
- 양쪽 패널에 문서 내용이 **그대로 그려짐** — "내가 올린 문서가 맞네" 즉시 인지
- 표가 셀 분리되어 보임 — `| 부품번호 | 명칭 |` 같은 파이프 텍스트 없음

### 약간 아쉬움 ⚠️
- 표 셀 내용 (`A-100`, `메인 컨트롤 보드`) 이 너무 작은 폰트 — 읽기 좀 부담
- 표 헤더 행이 **하이라이트 표시 안 됨** — "이게 자동 제외됐다" 라는 시각 신호 부재 (자동 제외 패널을 펼쳐야 알 수 있음)

## 3. 시각 인상

### 매우 좋음 ✅✅
- **본문 → 표 → 본문 자연스러운 흐름** — 원문 느낌 그대로
- 매칭된 본문 4단락 모두 **분홍 배경** (의역 카테고리 색상) — 한눈에 어디가 비슷한지 보임
- 표는 매칭 안 됐으므로 일반 배경 — 시각 위계 명확
- 양쪽 문서가 좌·우 정렬되어 직관적 비교

### 시각 캡처에서 확인된 효과
| 요소 | 시각 |
|------|------|
| 본문 단락 (의역 매칭) | 분홍 배경 + 좌측 색 띠 |
| 본문 단락 (미매칭) | 일반 배경 |
| 표 (헤더 + 데이터 행) | 셀 분리 + border 적용된 진짜 표 |
| 점수 카드 | "66.7% 상당량 매칭" + 카테고리 분포 (의역 4) |

→ Copyleaks/Turnitin 와 비교해도 손색 없는 시각 마감.

## 4. 사용 흐름 직관성

### 매우 직관적 ✅
1. **유사도 모드 진입** — 큰 카드 3개 (유사도 검사 / 문서 비교 / 규칙 검증) 명확
2. **파일 업로드** — 드래그 앤 드롭 또는 파일 선택 버튼 — 표준 패턴
3. **검사 실행** — 양쪽 다 업로드되면 검사 버튼 활성화. 비활성 상태일 땐 회색
4. **결과 보기** — 점수 + 카테고리 분포 + 사이드바 카드 자동 노출

### 카드 클릭 → 패널 동기 스크롤 (Plan-51 효과)
- 카드 클릭 시 양 패널이 동시에 매칭 위치로 스크롤
- A·B 양쪽 모두 색상 강조됨 (sim-active outline)
- "이 문장과 저 문장이 매칭됐구나" 명확
- **이전엔 좌측만 가고 우측 안 갔던 페인 해소됨** (Plan-51)

### 검사 설정 토글 (Plan-52 hotfix1 효과)
- "검사 설정" 펼침 → 6개 토글 노출 (정형구문 / 짧은 매칭 / 목차 / 표·그림 캡션 / 인용·출처 / **표 헤더·구조 행**)
- 마지막 6번째 새 토글이 다른 5개와 동일 디자인
- 토글 변경 시 점수 즉시 재계산
- 가이드 ⓘ 버튼 → 모달에서 각 토글 상세 설명

## 5. 결과 신뢰도

### 점수 합리성 ✅
- 4단락 본문이 모두 의역 매칭 + 1건 표 헤더 자동 제외
- 분자: 4 (의역 매칭) / 분모: 6 (전체 7 - 자동 제외 1) ≈ **66.7%**
- "상당량 매칭" 라벨 — 합리적 (50-74% 범위)
- **사용자 직관과 점수 일치** — "본문이 거의 다 의역됐으니 표절 의심" 방향

### 카테고리 분포 ✅
- 동일 0, 거의 동일 0, 의역 4, 약한 유사 0, 제외 1
- 의역 카테고리 정확 분류 (본문은 단어 차이 있는 의역)
- 표 헤더 자동 제외 = "구조 행이라 점수 미반영" 정직 표시

### 자동 제외 동작 (Plan-52 효과) ✅✅
- "제외 1건 보기" 클릭 → "자동 1 · 수동 0" + 카테고리별 분리
- 표 헤더 (`| 부품번호 | 명칭 | 수량 |`) 가 정확히 자동 제외로 분류
- **이전엔 표 헤더가 100% 일치로 분자에 포함되어 점수 inflation 됐던 문제 해소**

### 토글 OFF 시 점수 정합 (Plan-52 hotfix1 효과) ✅
- "표 헤더·구조 행 제외" OFF 클릭 → 점수 즉시 변동
- 백엔드 점수와 프론트엔드 재계산 점수 **100% 일치**
- silent 변동 없음

## 6. 좋은 점 (Plan-50 ~ 53 누적 효과)

### Plan-50 — 점수 공식 v3
- 의역 가중치 0.5 → 1.0 으로 변경되어 직관적 (Copyleaks 표준)
- 분모가 sentence index set 기반 → 카드 분포와 무관하게 안정적

### Plan-51 — 매칭 병합 ri 단방향 결함 수정
- 카드 클릭 시 **양 패널 동시 스크롤** — 이전엔 좌측만 가고 우측 안 갔던 페인 해소
- 의역 카테고리에서 발생하던 silent 미동기 사라짐

### Plan-52 본체 — 시각 보존 + 구조 행 자동 제외
- **표가 진짜 `<table>` 로 렌더** (이전엔 `| 셀1 | 셀2 |` 파이프 텍스트)
- 표 헤더 자동 제외로 **100% 오탐 해소**
- 사용자 시각 인지 = "이 도구는 표를 알아본다"

### Plan-52 hotfix1 — 프론트 토글 통합
- 6번째 토글 정상 노출
- 토글 ON/OFF 즉시 점수 재계산
- 가이드 모달에 새 항목 설명

### Plan-53 — DOCX 본문/표 원본 순서 보존
- **표가 본문 사이에 자연스럽게 위치** — 이전엔 모든 표가 문서 끝에 모이는 결함
- 페이지 마커 정합
- 사용자 인지: "내 문서 그대로 보여준다" 신뢰 회복

→ **5건의 누적 개선이 한 시나리오에서 모두 작동** 사용자 경험 종합 정합.

## 7. 부족한 점 / 개선 제안

### 발견된 부족함

#### 1. 표 헤더 자동 제외 시각 신호 부재 (보통)
- 표 헤더가 자동 제외됐다는 게 **본문 패널에서는 안 보임**
- 자동 제외 패널을 펼쳐야 비로소 인지
- **제안**: 자동 제외된 표 행은 좌측에 회색 테두리 또는 어두운 배경으로 살짝 표시

#### 2. 표 셀 폰트 작음 (보통)
- 본문 단락보다 표 셀 텍스트가 작게 보임 — 길거나 많은 데이터 표 검토 시 부담
- 일반 페이지 폰트 크기로 통일하거나 약간 키우면 좋을 듯

#### 3. 카테고리 분포 카드 위치 (낮음)
- "동일 0, 거의 동일 0, 의역 4..." 카드가 점수 바로 아래라 직관적
- 단, 의역만 4건인 경우 다른 카테고리 0 표시가 시각 노이즈
- **제안**: 0인 카테고리는 흐리게 처리하거나 숨김 옵션

#### 4. 자동 제외 1건의 카드 위치 (낮음)
- 메인 카드 영역에는 의역 4건만, 표 헤더 1건은 "제외 1건 보기" 펼쳐야 노출
- **제안 (반대 의견 가능)**: 펼침 default ON 하면 "이 표 헤더가 자동 제외됐다" 즉시 인지 가능. 단 사이드바 길어짐 트레이드오프

### 개선 우선순위
1. (보통) 표 헤더 자동 제외 시각 신호 — 패널 안에서도 약하게 표시
2. (보통) 표 셀 폰트 살짝 키우기 (12px → 13px 정도)
3. (낮음) 0 카테고리 표시 정리
