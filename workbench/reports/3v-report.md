## 3. 규칙 정확도 측정 (3V-c, 3V-d)

### 양호 문서 정밀 측정 (18 paragraphs, 229 words)

| 분석 항목 | 기대 | 실제 | 정확도 |
|----------|:----:|:----:|:------:|
| 헤딩 감지 | 4개 | 4개 | 100% |
| 표 감지 | 3개 | 3개 | 100% |
| 그림 감지 | 2개 | 2개 | 100% |
| shall 분류 | 6개 | 6개 | 100% |
| 규격번호 추출 | 2개 (461G, 464C) | 2개 | 100% |
| 약어 추출 | 2개 (EMI, EUT) | 1개 (EUT) | 50% |
| 단위 추출 | 3개 (kHz, MHz, GHz) | 3개 | 100% |

**종합**: 7/8 항목 정확 = **87.5%**

### 약어 미감지 원인

`EMI`가 "electromagnetic interference (EMI)" 형태로 나타나는데, 현재 패턴은 대문자 연속 약어를 먼저 찾고 괄호 정의를 매칭합니다. 이 경우 "EMI"가 괄호 안에 있어 주요 패턴(`EMI (Electromagnetic Interference)`)과 역순이므로 미감지됩니다.

→ **Phase 5에서 약어 패턴 확장 시 해결 가능** (역방향 정의 패턴 추가)

### 오탐률 (False Positive)

|--------|:---------:|:---------:|:----:|

| 깨끗한 짧은 문서 | 0건 | 0건 | 0건 |
| 연속 번호 + 참조 완비 | 0건 | 0건 | 0건 |

## 5. 겉보기 vs 실질 갭 분석

| 기능 | 겉보기 인상 | 실질 가치 | 판정 |
|------|-----------|----------|:----:|
| 도넛 차트 점수 | 시각적으로 강렬 | **실질적** — 업계 근거 기반 공식으로 개선됨 | ✅ 유지 |
| 카테고리별 바 차트 | 직관적 분포 | **실질적** — 백엔드 동일 공식으로 일관 계산 | ✅ 유지 |
| 헤딩 트리 | 문서 구조 시각화 | **실질적** — 정확도 100% | ✅ 유지 |
| 요구사항 분류 | shall/should/may 통계 | **실질적** — INCOSE 표준 방법론 | ✅ 유지 |
| 규격번호 목록 | 자동 추출 | **실질적** — 정확도 100% | ✅ 유지 |
| 약어 목록 | 자동 추출 + 정의 | **부분적** — 역방향 정의 미감지 (50%) | ⚠ Phase 5 개선 |
| 단위 표기 | SI 준수 표시 | **부분적** — 감지는 정확하나 SI 판정 기준 제한적 | ⚠ Phase 5 개선 |

### 제거 대상: 없음

모든 기능이 실질적 가치를 제공합니다. 약어/단위의 부분적 한계는 Phase 5 표준 규칙 도입으로 해결됩니다.

## 6. Phase 5 우선순위 권고

| 순위 | 영역 | 근거 |
|:----:|------|------|
| 1 | **STE 문장 규칙** (수동태, 명사 클러스터) | 현재 미존재, 작성 품질의 핵심 |
| 2 | **MIL-STD 구조 규칙** (필수 섹션, 순서) | 현재 헤딩만 감지, 구조 검증 깊이 부족 |
| 3 | **약어 패턴 확장** | 역방향 정의 미감지 → 정확도 50% |
| 4 | **규칙 엔진 리팩터** (JSON 스키마) | 6종 하드코딩 → 확장 불가, 엔진 선행 필수 |
| 5 | **스코어링 가중 평균** | 카테고리 중요도 차등 반영 (설정 가능) |

> **권장 착수 순서**: 5c(스키마) → 5d(엔진) → 5e(마이그레이션) → 5f(STE) → 5g(MIL-STD)
