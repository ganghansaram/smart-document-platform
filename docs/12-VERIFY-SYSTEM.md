# Verify 시스템 — 설계 및 표준 규칙 기준 문서

문서 비교 / 유사도 검사 / 규칙 검증 도구. 3개 표준(ASD-STE100, MIL-STD-961E, MIL-STD-38784B) 기반 규칙 엔진 탑재.

---

## 1. 시스템 개요

Verify는 기술문서의 **비교(Diff)**, **유사도 검사(표절 점검)**, **규칙 검증(품질 게이트)** 3모드를 제공한다.

| 모드 | 알고리즘 | 출처 |
|------|---------|------|
| 비교 | jsdiff (단어 수준 diff) + AI 의미 분류 | 업계 표준 |
| 유사도 | Winnowing L1 + bge-m3 L3 | MOSS(Stanford) + BAAI |
| 검증 | 정규식 + 휴리스틱 규칙 엔진 | 아래 표준 기반 |

---

### 6.5 향후 확장: NLP 도입 시 적용 가능 규칙

현재 "NLP 필요"로 미적용된 18건은 경량 NLP(spaCy 등, 모델 ~15MB) 도입 시 적용 가능하다. 현 환경에서 LLM(수 GB)을 이미 운용 중이므로 기술적 제약은 없다. 현재 적용된 구조 검증 규칙만으로 사내 기술스펙 작성 검증에 충분하며, 스타일 품질 강화가 필요한 시점에 단계적으로 도입을 권장한다.

| 도입 시 추가 가능 규칙 | 예상 효과 |
|----------------------|----------|
| 수동태 정확 감지 (STE 3.6) | precision 60% → 90%+ |
| 품사 기반 명사 클러스터 (STE 2.1) | 오탐 대폭 감소 |
| 동사 형태 검증 (STE 3.1~3.5) | 5건 추가 적용 |
| 적용률 변화 | 24% → 약 40~50% |

## 7. 스코어링 방식

Acrolinx density 방식 채택 (Phase 3V에서 업계 조사 후 결정):

```
severity_weight = { error: 5, warning: 2, suggestion: 1 }
confidence_weight = { high: 1.0, medium: 0.7, low: 0.4 }

issue_weight = severity_weight × confidence_weight
density = sum(issue_weights) / (effective_words / 100)
score = 100 × max(0, 1 - density / threshold)
```

| B | 70~89 |
